# Archery Game – Flutter Project

This repository contains an **Archery Game** developed using **Flutter**.  
The project is built with a cross-platform Flutter structure and can be used as a practice, portfolio, or learning project for game development with Dart and Flutter.

## Project Overview

The main objective of this project is to create a simple archery-style game using Flutter.  
The game focuses on basic gameplay logic, user interaction, scoring concepts, and Flutter-based UI development.

## Key Features

- Archery game concept built with Flutter
- Cross-platform Flutter project structure
- Supports Android, iOS, Web, Linux, and Windows project folders
- Clean Dart source code organization inside the `lib/` folder
- Basic game logic implementation
- Simple and beginner-friendly Flutter project
- Suitable for learning mobile game development

## How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/sudeepmondal/Archery_Game__Flutter-Project.git
```

2. Go to the project directory:

```bash
cd Archery_Game__Flutter-Project
```

3. Get Flutter dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

## Build Commands

For Android APK:

```bash
flutter build apk
```

For Web:

```bash
flutter build web
```

For Windows:

```bash
flutter build windows
```

For Linux:

```bash
flutter build linux
```
